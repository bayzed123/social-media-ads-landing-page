# Ecommerce Full‑Stack Website বিক্রির জন্য Meta Messages Campaign Setup

## 1. Budget assumption

আপনার লেখায় **৳১,০০০/day**, **৳২০০ total**, এবং **৫ দিন**—তিনটি সংখ্যা আছে। এগুলো একসাথে সম্ভব নয়। এই setup-এ আমি ধরে নিচ্ছি:

- **Daily budget:** ৳১,০০০
- **Duration:** ৫ দিন
- **Expected total spend:** প্রায় **৳৫,০০০**
- যদি আপনার আসল total budget মাত্র **৳২০০** হয়, এই campaign চালাবেন না; এত কম budget-এ meaningful message test হবে না।
- যদি আপনার আসল budget **৳২০০/day** হয়, একই setup রাখুন, কিন্তু ১টি ad set ও ১টি creative দিয়ে চালান।

৫ দিন আপনার test window হিসেবে চলবে, তবে Meta নিজেই click-to-message campaign-কে স্থিতিশীল ফলের জন্য **৭ দিন বা তার বেশি** চালানোর পরামর্শ দেয়। তাই ৫ দিনের data-কে final winner ধরে সিদ্ধান্ত নেবেন না। [1]

## 2. Campaign-এর মূল লক্ষ্য

আপনার লক্ষ্য শুধু likes বা comments নয়; লক্ষ্য হলো এমন ব্যবসার মালিককে WhatsApp conversation-এ আনা, যিনি online store বানাতে চান। তাই campaign হবে:

- **Campaign objective:** Engagement
- **Engagement goal / conversion location:** Messages
- **Primary destination:** WhatsApp
- **CTA:** Send WhatsApp Message / Send Message
- **Optimization:** Conversations, যদি Ads Manager-এ option থাকে
- **Campaign name:** `BD | Ecommerce Fullstack Website | WA Messages | 5D Test`

Meta-এর Engagement objective-এ Messages optimization ব্যবহার করে Messenger, Instagram অথবা WhatsApp-এ conversation আনা যায়। Click-to-message ad মানুষকে সরাসরি conversation-এ পাঠায়। [2] [3]

### WhatsApp setup আগে ঠিক করুন

1. Facebook Page-এর সঙ্গে WhatsApp Business number **+8801519601517** connect করুন।
2. WhatsApp Business profile-এ logo, service description, working hours এবং website/demo link রাখুন।
3. Meta Business Suite Inbox-এ Facebook, Instagram এবং WhatsApp message একসাথে দেখুন।
4. Instant reply চালু করুন, কিন্তু bot যেন শুধু price না বলে—প্রথমে business type, product count এবং required features জিজ্ঞেস করবে।

## 3. Recommended campaign structure

৳১,০০০/day হলে প্রথম ৫ দিনের জন্য **ABO** ব্যবহার করুন, যাতে দুই ধরনের audience-এ spend control থাকে।

### Ad set A — High-intent business audience

- **Budget:** ৳৬০০/day
- **Location:** Bangladesh
- **Age:** ২৪–৪৪
- **Gender:** All
- **Language:** blank রাখুন; language restriction দিলে সম্ভাব্য buyer বাদ পড়তে পারে
- **Audience setting:** Advantage+ audience ON রাখুন
- **Audience suggestions / detailed-targeting suggestions:** account-এ যেগুলো available থাকে সেগুলোর মধ্যে ৩–৬টি বেছে নিন:
  - Entrepreneurship
  - Small business
  - Business owner
  - E-commerce
  - Online shopping
  - Digital marketing
  - Shopify
  - WooCommerce
  - WordPress
  - Web design / Website

Meta-এর Advantage+ audience আপনার suggestions, previous interactions এবং অন্যান্য signals ব্যবহার করে audience expand করতে পারে। Meta নিজেই broad targeting-এর সঙ্গে Advantage+ audience test করার পরামর্শ দেয়। [4]

**গুরুত্বপূর্ণ:** সব interest একসাথে stack করে audience খুব ছোট করবেন না। Ads Manager-এ available না থাকা interest-এর নাম জোর করে ব্যবহার করবেন না। Targeting interface-এ যে option দেখাবে, শুধু সেটিই নিন।

### Ad set B — Broad owner/decision-maker test

- **Budget:** ৳৪০০/day
- **Location:** Bangladesh
- **Age:** ২৪–৪৪
- **Gender:** All
- **Detailed targeting:** None
- **Advantage+ audience:** ON
- **Creative:** একই primary creative

এই broad ad set রাখার কারণ হলো Meta-এর delivery system আপনার manually chosen interest-এর বাইরেও buyer signal খুঁজতে পারে। ছোট budget-এ অতিরিক্ত interest restriction delivery ও learning কমিয়ে দিতে পারে।

### যদি budget ৳২০০/day হয়

দুই ad set চালাবেন না। শুধু একটি ad set চালান:

- Bangladesh, age ২৪–৪৪, all genders
- Advantage+ audience ON
- ১টি creative
- WhatsApp destination
- ৳২০০/day × ৫ দিন = ৳১,০০০ total test

## 4. Placements

- **Recommended:** Advantage+ placements ON
- Facebook Feed
- Instagram Feed
- Instagram Stories/Reels
- Facebook Stories/Reels
- Messenger placement, যদি Ads Manager দেয়

Meta-এর official experiment-এ Advantage+ placements manual placements-এর তুলনায় average CPA কমিয়েছে; Meta বিভিন্ন placement-এ delivery দিয়ে cost-effective opportunity খোঁজে। [5]

প্রথম ৪৮ ঘণ্টা placements বন্ধ করে রাখবেন না। Day 3 থেকে breakdown দেখুন:

- কোন placement থেকে real conversation এসেছে
- কোন placement থেকে শুধু click বা empty message এসেছে
- কোন placement-এ cost per conversation বেশি

শুধু junk placement স্পষ্টভাবে বেশি হলে সেই placement বাদ দিন। শুরুতেই Feed only করে audience ছোট করবেন না।

## 9. Five-day operating plan

### Day 1 — Launch এবং quality check

- Ad active হওয়ার পর নিজে WhatsApp click করে দেখুন।
- Message ঠিকভাবে আপনার WhatsApp-এ যাচ্ছে কি না দেখুন।
- Creative crop, Bengali text, CTA এবং link পরীক্ষা করুন।
- Comments-এ price জিজ্ঞেস করলে public reply দিন: `Inbox/WhatsApp-এ requirement পাঠান, আমরা details দিচ্ছি।`

### Day 2 — No major edit

শুধু দেখুন:

- Delivery হচ্ছে কি না
- Cost per messaging conversation
- কতজন real question করছে
- Audience/placement কোথা থেকে message আসছে

দুপুরে একবার এবং রাতে একবার inbox reply দিন। একই দিনে বারবার budget বা audience edit করবেন না।

### Day 3 — Quality-based decision

শুধু message count দেখে winner বাছবেন না। এই তিনটি metric দেখুন:

1. **New messaging conversations**
2. **Qualified conversations** — business, product এবং budget নিয়ে serious প্রশ্ন
3. **Cost per qualified conversation**

যে ad set message আনে কিন্তু কেউ business information দেয় না, সেটিকে winner ধরবেন না।

### Day 4 — Small adjustment

- কোনো ad set clearly better হলে তার budget সর্বোচ্চ ২০–৩০% বাড়ান।
- খারাপ ad set বন্ধ করার আগে অন্তত কিছু delivery ও conversation data দেখুন।
- Weak comments বা low-quality messages হলে caption-এ qualifying line আরও স্পষ্ট করুন।

### Day 5 — Follow-up ও decision

প্রতিটি serious lead-কে follow-up দিন:

```text
আপনার website requirement-এর জন্য আমরা live demo, feature list এবং estimated cost দিতে পারি। আপনি কি আজকে ১০ মিনিটের একটি WhatsApp call বা chat করতে পারবেন?
```

শেষে report করুন:

- Total spend
- Total conversations
- Qualified leads
- Demo requests
- Quotation requests
- Sales closed
- Cost per qualified lead

## 10. What counts as a successful result

এই ৫ দিনের campaign-এর প্রথম লক্ষ্য sale নয়; প্রথম লক্ষ্য হলো **qualified buyer conversation**। একজন qualified lead সাধারণত:

- নিজের business category বলে
- product count বা catalogue নিয়ে প্রশ্ন করে
- admin/order/checkout feature জানতে চায়
- price, delivery time বা demo চায়
- নিজের page বা business link শেয়ার করে

শুধু reactions, cheap clicks বা “hi” message campaign success প্রমাণ করে না।

## 11. Audience mistakes এড়িয়ে চলুন

- শুধু “online shopping” interest target করবেন না; এতে buyer/customer audience বেশি আসতে পারে, website buyer নয়।
- Age ১৮–৬৫+ করে budget ছড়িয়ে দেবেন না। শুরুতে ২৪–৪৪ decision-maker range ব্যবহার করুন।
- এক campaign-এ ৫–৬টি ad set বানাবেন না। ৳১,০০০/day-এ দুইটি ad set যথেষ্ট।
- Caption-এ শুধু “website বানাই” লিখবেন না; storefront + admin dashboard + business outcome দেখান।
- Instant reply ছাড়া message campaign চালাবেন না।
- ৫ দিনের result দিয়ে lifetime audience judgement করবেন না; এটি test data।
